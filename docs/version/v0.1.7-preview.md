# v0.1.7 预览版：第三方客户端互操作与 CLI

> 状态：本轮认领范围已实现并通过五平台构建与验证；2026-11-18 准备合并主分支及发布 Preview，标签构建结果随后记录。基线为 0.1.6 发布后的 `main`（`590e056`），开发分支 `codex/v0.1.7-interop`；开发验收源码为 `af8cc1f`，详见[验收记录](../testing.md#017-互操作与-cli-构建验收)。本轮认领 P0 工作包 4 / 5 / 7.4 及工作包 6 的文档；公共 SDK 发包和其他策略扩展不纳入。编号见[基线登记册](baseline-0.1.3.md)；实现者从[客户端接入](../sdk.md)开始。

## 主题与目标

交付的是可以独立实现的协议文档、共享测试向量和可排错的 CLI，不是三个必须发布的 SDK。外部作者可选任意语言、只实现需要的能力，无需依赖仓内 SDK 或向项目申请成为客户端作者。现有 Rust / Go / Java 源码继续用作互操作样本；CLI 确实依赖仓内 Rust 客户端，不能因此跳过 CLI 回归。

## 分级与门槛

- **P0：工作包 4、5 的协议契约，以及 7.4 的 CLI 确认语义。** 只靠公开规范和夹具即可校验握手、类型、错误、响应匹配与发送后结果未知；已有服务端和 CLI 在真实连接上回归。支持订阅或 Batch 的实现另验相应能力，未实现的不宣称支持。
- **P1/P2：可选维护。** SDK 上架、连接池、重试策略、各语言示例不是本版或稳定版的前置条件。维护者或第三方如愿认领，可按下列包实施；不要求第三方照搬官方 API。未发布、未执行或跳过均据实记录。
- 不改协议 v1、命令语义或错误码，不新增官方 TypeScript SDK。包版本、产品版本与协议版本彼此独立；客户端按能力和协议版本说明兼容性。

## 工作包 4：断线与重试边界（P0 契约已实现，本机通过；策略实现不认领）

当前实现单连接串行，默认不重放请求。契约必须说明何时可确认为未发送、何时结果未知；实现只需明确失败，不必提供连接池、自动重连或白名单重试。以下恢复选项仅供认领者参考。

| 任务 | 来源 | 做法 | 验收 |
|---|---|---|---|
| 4.1 策略对象（可选） | C-04 | 如提供自动恢复，显式启用；设置有界的尝试次数、退避、单次与总期限 | 关闭策略时无自动重试；异常参数被拒绝，超时不掩盖结果未知 |
| 4.2 可重试范围 | C-04 | 只有两类：请求尚未发送时的连接建立失败；以及显式白名单内的只读命令在发送后连接失效。白名单由命令表逐条列出，写入 sdk.md 与共享用例，不凭「看起来只读」推断。SCAN 不在其中（游标绑定连接）；写命令、订阅、ACK、SELECT、AUTH、HELLO 一律不在其中。读取会更新 LRU / LFU 热度（config.md），重试可能多更新一次，文档注明，不改变 revision | 白名单与 commands.md 的只读命令由脚本对照；新增命令时 CI 要求显式归类 |
| 4.3 池与租约（可选） | C-04、C-12 | 池如存在，应淘汰已知失效的空闲连接，重建后重新完成 HELLO / AUTH / SELECT；保活或借出前检查不能保证随后不掉线。SCAN 游标不跨连接 | 对照发送前可证失效、写出后失联、租约内断线三条路径；不把有歧义的写重发，不在新连接静默续扫 |
| 4.4 订阅 | C-04 | 提供带退避的重新订阅辅助：重连后先比较 stream_id，不一致报 ERR_STREAM_MISMATCH 并停止；遇 ERR_OFFSET_EXPIRED 停止并交调用方处理，不自动换组名、不跳到尾部（events.md） | 用例：流身份变化、Offset 过期、取消与关闭时释放专用连接 |
| 4.5 传输契约 | C-04、C-12 | 用本地测试对端在发送前、发送后及响应中断开，共用一份与实现语言无关的预期结果 | 已知未发送与结果未知可区分；传输失败不重复执行写入，若提供池则检查固定库与失效连接回收 |

关键断言：传输失效后不能宣称已回滚，默认不重试。只对主动提供只读重试的实现验证白名单、次数和总期限。

## 本轮实现与本机验收

共享 `sessions.tsv` 有 41 个用例，覆盖普通请求、Batch、订阅控制、空闲订阅、发送前失败、发送后断线与截断、失效租约回收和固定库。修复 Rust 旧响应及 Batch 解码分类、三语言空闲订阅的响应匹配、Go / Java 的 ERROR ID0 保留，以及 Go 在关闭与执行许可同时就绪时误尝试发送的问题。默认不重放请求，未添加重试白名单或自动订阅恢复策略。

CLI 已区分 stdin EOF 与主动取消，新增七语言 `LOCAL_SUBSCRIPTION_UNACKNOWLEDGED` 诊断。EOF、显式 ACK、自动 ACK 和输出失败的真实子进程测试用命名组重投核对；同一 Ctrl-C 监听贯穿事件与确认等待，避免输出期间丢失取消。Unix 真实 SIGINT 用例已在四个原生任务通过，Windows 本机只验证内部取消选择与其余子进程路径。

2026-11-17 本机 Windows：最终默认配置 workspace 231 项、关闭更新器配置 212 项测试通过，0 失败、0 ignored；三语言显式 Fast 驱动各 41 个 local-peer、105 个 TCP、105 个双向 TLS 用例通过，均无失败、跳过或漏跑。本机未启用 Go race（无 cgo）；Linux Actions 的相同计数已在 Reliable 与 race 开启时通过。Python 23 项工具回归、格式、两种配置的严格 Clippy、严格 rustdoc 及文档站构建/链接检查通过。服务端与 CLI 的 release 构建及真实 TCP 烟测通过。普通本机 workspace 未设置产物的提前返回不计作来源证明验证；下载最终 Actions 产物后，显式设置目录与分支 ref 的真实验签已单独通过。

Actions `44109461968` 的五平台构建、安装升级、14 个包与 14 份 SBOM、三系统独立验签全部通过；下载的 31 个附件已核对摘要、SBOM schema、离线来源证明及 Windows 便携包烟测。该次由开发分支手动触发，发布任务按条件跳过，没有创建 `v0.1.7` 标签或 GitHub Release。

本轮不发布公共 Go / Java / Rust 包，不新增行编辑、持久历史或机器可读输出；决定见 [decisions.md](../decisions.md#017-客户端与-cli-范围决定2026-11-17)。0.1.6 记录的 Windows 11 / 原生 RPM / UAC、平台签名、公证和新更新器公开跨版本验收限制仍保留。
